# Falcon Ventures Pvt. Ltd. — Presentation Demo

A presentation-first React, Vite and TypeScript website for Falcon Ventures Pvt. Ltd. The site includes informational company pages and illustrative property demo listings.

## Run locally

From this directory:

```sh
pnpm install
pnpm dev
```

Create a production build with `pnpm build`, or run the TypeScript check with `pnpm typecheck`.

## Important

Property names, specifications, locations and displayed PKR prices are demo content only and are subject to verification. The demo does not assert that Falcon Ventures owns or has verified any listed property. The contact form validates locally and only displays an in-browser confirmation; it does not transmit or store submissions. Architectural photos are linked from Pexels public image URLs.
